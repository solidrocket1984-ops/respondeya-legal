# Borradores — Capa Privada

Los documentos de esta carpeta son **borradores de trabajo**, sin efecto legal, para que Xavi los revise.

- No están publicados en legal.respondeya.es.
- No deben enlazarse desde la web, el Panel, la extensión ni comunicarse a clientes.
- No sustituyen ni modifican los Términos (v3.2) ni la Política de Privacidad (v2.7) vigentes.

Pasan a tener efecto solo cuando Xavi los apruebe y se publiquen, con su propia fecha y número de versión, en las páginas correspondientes (`/terminos`, `/privacidad` y las fichas de las tiendas de extensiones).

## Contenido

- `capa-privada-anexo-terminos.md` — borrador de anexo a los Términos para el producto Capa Privada.
- `capa-privada-privacidad.md` — borrador de apartado de la Política de Privacidad para Capa Privada.
- `capa-privada-tiendas-politica-privacidad.md` — versión corta (ES/EN) para las fichas de Chrome Web Store y Edge Add-ons.
